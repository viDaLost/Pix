# Бестиарий Велена

Летопись чудовищ, 1740. Город Велен, осень. Игроку достался бестиарий прежнего хранителя Даро: многое в нём записано
верно, многое со слухов, а многого нет вовсе. Каждый день в скрипторий приходят охотники с делами — «волколак в
Заречье», — и летописец пишет им ровно **три указания** из своего бестиария. Каждое верное указание даёт треть успеха,
три верных — победу наверняка. Утром охотник возвращается — с наградой или побитым — и по каждому указанию рассказывает,
что вышло: «Помогло», «Без толку», «Во вред». Печати в бестиарии меняются сами.

**Играть:** https://viDaLost.github.io/Pix/

Мобильная офлайн-игра (PWA) на чистом JavaScript: ES-модули без сборщика и сервера, пиксельная сцена на canvas,
русский интерфейс. Таймеров, серий входа и лутбоксов нет; время идёт только по кнопке «Задуть свечу»; охотники не
гибнут — раненый лечится до четырёх дней.

## Как играть

- **Приёмная** — гости дня. «Открыть лист» → выбери три листка сведений (не больше одного на род: чем бить, чем
  уберечься, когда, где, как) и до двух снадобий. Полоса под листом показывает оценку **по твоим записям**:
  «Надёжно N%», а «от» и «до» — что будет, если слухи окажутся вредными или верными. Сведение с печатью «Опасно»
  советовать нельзя. «Отложить» — дело придёт завтра с завтрашней погодой; «Отказать» — без штрафа.
- **Утро** — отчёты вернувшихся: печать на каждое указание, рана или награда на выбор (монеты, добыча — части чудовища
  для опытов, или знание — новое сведение и полевые записи).
- **Бестиарий** — страницы чудовищ: печати, счётчики, последние обстоятельства, пометки на полях.
- **Опыты** — проверка средств и оберегов на образцах, сверка времени, места и обряда по полевым запискам, поиск в
  летописях, алхимия.
- **Лавка** — травы, книги и листки-слухи, лист Академии (каждая проверенная запись продаётся один раз), трактаты,
  обустройство скриптория и снаряжение охотников.
- **Летопись** — звание, вехи, трофеи и дни.

За ~40 игровых дней приходит Чёрная зима, и последнее дело — колдун Мартын. Цель — четырнадцать трактатов и печать
«Великого бестиария»; после неё игра продолжается.

## Сохранения и прежняя игра

Бестиарий сохраняется на устройстве: IndexedDB `pix-bestiary` (хранилище `saves`) и зеркало
`localStorage['pix-bestiary-save-v1']`, если сохранение меньше 1,5 МБ. Запись идёт одним пакетом через 400 мс после
действия и сразу при уходе со страницы. Вторая вкладка не перезапишет более новое сохранение: она остановится и
предложит перезагрузку. Через меню сохранение скачивается файлом (`bestiary-day-N.json`) и загружается обратно; перед
загрузкой или новым началом прежний бестиарий откладывается, и его можно вернуть из меню.

Сохранение прежней игры — ювелирной мастерской «Сияние» — не трогается: если оно найдено, меню предлагает «Скачать
сохранение прежней игры» (файл `siyanie-save.json`, байт в байт). В бестиарий оно не переносится.

## Разработка и GitHub Pages

Требуется Node.js 22+. Установка npm-зависимостей не нужна.

```sh
npm start          # http://localhost:4173/Pix/
npm run check      # синтаксис всех модулей, скриптов и тестов
npm test           # node:test
npm run balance    # бот баланса; --write обновляет docs/BALANCE.md
npm run build      # dist/ для GitHub Pages
```

Workflow `.github/workflows/pages.yml` проверяет синтаксис, правила и экономику, собирает игру и публикует `dist/`
при push в `main`. Service worker кэширует все файлы из `FILES` в `sw.js` под именем `pix-bestiary-…` (имя меняется
с каждой сборкой) и при активации убирает старые кэши обеих игр; игра запускается без сети. `?fps` в адресе показывает
среднее время кадра сцены (бюджет — 6 мс на слабом телефоне).

## Код и проверки

| Файл | Назначение |
| --- | --- |
| `src/content-data.js` | Весь контент: 14 чудовищ и 109 сведений, охотники, гости, снадобья, книги, сюжет, звания, строки |
| `src/lore.js` | Единственный вход к контенту: индексы, склонения, подстановки `{м\|ж}` и `{monster}` |
| `src/rng.js` | Детерминированный бросок по зерну мира и ключу события |
| `src/rules.js` | Чистая математика: исход сведения, шанс охоты, оценка игрока, раны, звания, полнота страницы |
| `src/bestiary.js` | Ядро: состояние, строгая загрузка, знание, дела дня, ночь охот, отчёты и все действия |
| `src/progress.js` | `normalize`, сюжет «Чёрная зима», арки охотников и обёртки `P.*` — интерфейс меняет игру только через них |
| `src/guide.js` | Очередь Приёмной, советы «Сегодня» и карточка «Утро» без DOM |
| `src/app.js` | Оболочка: HUD, пять вкладок, лист совета, отчёт, окна, меню, сохранения |
| `src/scriptorium-scene.js` | Пиксельный скрипторий 480×260: окно с небом, погодой, Чёрной зимой и оттепелью; свечи дня, трофеи, трактаты, склянки, банки, обустройство; гости, вернувшиеся охотники, Даро, Магистр и Федя; полоса «Лаборатория» и «Порог» отчёта |
| `src/item-art.js` | Пиксельные значки трав, частей и товаров, склянки снадобий с уровнем доз, трофеи стены |
| `src/store.js` | IndexedDB-хранилище с защитой вкладок (`openStore`) и чтение сохранения «Сияния» (`readLegacy`) |
| `src/notices.js` | Очередь тостов и порядок окон `MODAL_ORDER` без DOM |
| `src/ambience.js`, `src/audio.js` | Время суток, погода и луна; процедурные звуки, музыка скриптория и лаборатории, звуки отчёта и вибрация |
| `src/characters.js`, `src/character-rig.js`, `src/motion.js`, `src/pixel.js` | Пиксельные люди: оружие охотников, оборванность после провала и личные приметы, позы летописца, хромота |
| `assets/fonts/` | Cormorant Garamond, Manrope и Marck Script (почерк на полях) — шрифты OFL, лицензии рядом |
| `scripts/bot.mjs`, `scripts/balance.mjs` | Бот баланса: пять стратегий играют только через `P.*` |
| `tests/*.test.mjs` | Правила, знание, день, экономика, сюжет, сохранения, офлайн, хранилище, линтер интерфейса |

# Кузница чудес

Мобильная пиксельная игра про кузницу и лавку магических товаров. Изготавливай вещи, добывай материалы, открывай технологии, перепродавай товары каравана и помогай жителям восстановить древний маяк.

**Играть:** https://viDaLost.github.io/Pix/

## Версия 2: живая мастерская

- Отдельные пиксельные локации кузницы и лавки. Мир рисуется на Canvas 480 × 320 без сглаживания, со слоями освещения, фактурой стен, инструментами и предметами на витринах.
- Проработанный кузнец с лицом, бородой, фартуком и отдельными движениями рук и ног. Ходьба в четырёх направлениях, разметка, работа с горячей заготовкой, удары молота, закалка и отделка. Нажимай на станцию или свободный пол, чтобы переместиться.
- 12 чертежей, железо, медь, бронза и лунный сплав; три магические руны.
- Пять обязательных этапов: две метки на заготовке, нагрев мехами, пять ударов, выбор охлаждения и отделка. Работа происходит у разных станций; выполненные этапы сохраняются. Для каждого этапа с проверкой реакции есть отдельная помощь мастера.
- Вода, воздух и масло дают разное качество и свойства. Точильный круг открывает полировку и заточку; руны наносятся при отделке.
- Восемь типов NPC с разными ролями, одеждой, вкусами и требованиями к качеству. Посетители входят, ходят к витринам и уходят после покупки. Разговор раскрывает предпочтения; отношения и выбранный товар влияют на бюджет.
- Пролистываемая витрина: кнопки и свайпы, свойства и качество каждой вещи. Три ценовые стратегии, ежедневный спрос, насыщение рынка и торг со своей ценой после открытия навыка.
- Закупка материалов, перепродажа готовых вещей, восстановление, изучение и разбор артефактов.
- Пиксельная карта с кузницей, лесом, шахтой, руинами, перевалом и маяком. Закрытые места показывают требования. Каждый открытый регион имеет свою сцену; экспедиция состоит из двух выборов: сбор, поиск тайника или помощь путнику.
- Древо из 15 связанных навыков в трёх ветвях: ремесло, торговля, путешествия. Каждые 30 опыта дают уровень и очко мастерства. Навыки также требуют монет, силы и предыдущих открытий.
- Покупка и улучшение наковальни, мехов, закалочной ванны, точильного круга, рунного резца и походного набора. Оборудование меняет сцены и рабочие возможности. Горн, верстак, витрины и ученик также улучшаются.
- Пять сюжетных заказов. Заказчики возвращаются на следующий день с материалами и новыми возможностями. После завершения истории игра продолжается.
- Автосохранение, экспорт и импорт прогресса. Сброс требует подтверждения.
- Установка на домашний экран и работа без сети после первого успешного запуска.

Это браузерная игра/PWA для телефонов. APK и публикация в App Store в эту версию не входят. Сервер, учётная запись, реклама и платные ускорители не требуются. Звуки включаются в меню.

## Запуск на компьютере

Нужен Node.js 22 или новее. Внешние зависимости отсутствуют.

```sh
npm start
```

Открой http://localhost:4173/Pix/ — этот путь повторяет размещение игры в проекте GitHub Pages. Для тестирования телефона в той же сети используй IP компьютера и порт 4173. Установка PWA и офлайн требуют HTTPS либо localhost.

```sh
npm run check
npm test
npm run build
node scripts/serve.mjs --dist
```

Готовые статические файлы появляются в `dist/`. Сборка включает только игру, графику и манифест. Сервис-воркер получает версию по хэшу содержимого, чтобы изменения обновляли офлайн-кэш. Все пути относительные; игра работает в `/Pix/` и в корне другого статического хостинга.

## GitHub Pages

В репозитории уже есть workflow `.github/workflows/pages.yml`. Он проверяет JavaScript, запускает тесты, собирает игру и публикует артефакт Pages при изменении `main`. Pull request проходит проверки без публикации.

Первичная настройка владельцем репозитория:

1. Открой **Settings → Pages**: https://github.com/viDaLost/Pix/settings/pages
2. В разделе **Build and deployment → Source** выбери **GitHub Actions**.
3. Открой **Actions → Test and deploy game to GitHub Pages**, нажми **Run workflow** и выбери `main`. Если предыдущая попытка публикации не прошла до включения Pages, перезапусти её.
4. После успешного задания `deploy` игра доступна на https://viDaLost.github.io/Pix/.

Workflow использует стандартный `GITHUB_TOKEN` с `pages: write` и `id-token: write` только в задании публикации. Дополнительные токены или секреты не нужны. Если Actions выключены, включи их для этого репозитория.

Альтернатива без Actions: выбрать **Deploy from a branch → main → / (root)**. Корень содержит готовую игру, поэтому публикация не требует сборки. При этом автоматический workflow предпочтительнее: он выполняет проверки и обновляет версию кэша при каждой сборке.

## Как играть

Начни с фонаря для Миры: **Кузница → Фонарь → Взять материалы и начать**. Персонаж подойдёт к складу. Нанеси две метки в отмеченной зоне, удерживай меха и отпусти в зелёной области, затем нанеси пять точных ударов. Выбери закалку и сборку. После этого **Заказы → Передать → Новый день**. Мира вернётся с рудой и откроет шахту.

Помощь мастера выполняет только текущий этап с умеренной точностью, а не создаёт вещь одним нажатием. Этапы разметки, нагрева и ковки также доступны с пробелом. Удар и движение кузнеца видны в самой локации. Масло требует ванны и термообработки, полировка и заточка — точильного круга.

В лавке сначала выбери гостя и поговори с ним, затем пролистай витрину и предложи изделие. Посетитель покупает одну вещь и уходит; утром появляются новые, а за 1 силу можно пригласить дополнительного гостя. Навык оценки показывает точный бюджет, навык торга открывает ввод своей цены. Две слишком дорогие попытки заканчивают торг; обычная продажа остаётся доступна.

Древо открывается отдельной кнопкой в шапке и нижней навигации. Открытые навыки отмечены зелёным, доступные — золотым, закрытые — серым. Нажми узел, чтобы увидеть эффект, стоимость и требования. Завершённая ручная работа даёт опыт, который нужен для дальнейшего развития. Готовая ручная вещь даёт 12 опыта, продажа посетителю — 6, сюжетный заказ — 18.

Силы тратятся на ковку, исследования и вылазки. Торговля и улучшение оборудования силы не тратят. Следующий день полностью восстанавливает их; реального ожидания и платы за пропуск дня нет. Перед сменой дня закончи заготовку или убери её, а из экспедиции вернись домой. Покупай материалы или добывай их. Бронза создаётся при ковке из железа и меди. Подсказки в заказах объясняют, какие технологии нужны для следующих глав.

Цена зависит от качества, материала, руны и спроса. Если покупатель не согласен, снизь цену или дождись другого дня. Одинаковые товары насыщают рынок в течение дня. Заказ часто выгоднее обычной продажи.

Клавиатура: удерживай пробел при нагреве и нажимай его для меток и ударов. Стрелки перемещают кузнеца по свободному полу. Остальной интерфейс доступен через Tab, Enter и Escape.

## Сохранение

Прогресс хранится в `localStorage` текущего браузера и домена. Он не синхронизируется между устройствами. Очистка данных сайта или приватный режим могут удалить прогресс: скачивай JSON через меню перед очисткой или переносом. Импорт сначала проверяет файл и показывает подтверждение замены.

Повреждённое сохранение не перезаписывается автоматически: меню позволяет скачать исходный файл. Если хранилище недоступно, игра показывает предупреждение, а экспорт продолжает работать. Формат версии 2 сохраняет заготовку, этапы работы, экспедицию, опыт, навыки, инструменты, покупателей и отношения. Сохранения `version: 1` автоматически переводятся в версию 2 с сохранением денег, предметов, чертежей, технологий и сюжетного прогресса. Отдельные удары внутри незаконченного этапа повторяются после перезагрузки.

## Структура и проверки

| Файл | Назначение |
| --- | --- |
| `src/game.js` | Чистая игровая логика, экономика, заказы и формат сохранений |
| `src/app.js` | Мобильный интерфейс, ковка, звук и сохранение |
| `src/art.js` | Собственная пиксельная графика, иконки и персонажи |
| `src/motion.js` | Маршруты персонажей, ходьба и события прибытия |
| `styles.css` | Адаптивная вёрстка с учётом безопасных зон телефона |
| `sw.js`, `manifest.webmanifest` | Установка и офлайн-кэш |
| `scripts/` | Сервер разработки и статическая сборка |
| `tests/*.test.mjs` | Проверки транзакций, NPC, этапов работы, древа, движения, миграции и полного прохождения |

Автотесты проверяют первый заказ и возврат награды, отказы без списания ресурсов, атомарность партий, требования заказов, цены и спрос, перепродажу, блокировки исследований, добычу, артефакты, улучшения, сохранения и восстановление после банкротства. Новые тесты проверяют порядок пяти этапов, расход материалов, отмену заготовки, закалку и отделку, обязательный разговор с NPC, ограничение торга, две остановки экспедиции, миграцию версии 1 и прибытие персонажей. Полное прохождение пяти глав из новой игры проверяется и через новый цикл: ручная работа, торговля с посетителями, экспедиции и древо навыков, без добавления денег или материалов.

Перед выпуском проверен интерфейс в Chromium на ширине 320, 390, 430 и 844 px: все пять рабочих этапов, перезагрузка на незавершённой заготовке, разговор и продажа NPC, витрина, экспедиция с перезагрузкой, древо, покупка оборудования, экспорт/импорт и офлайн. Физические устройства iOS/Android следует дополнительно проверить перед магазинным релизом. При изменении баланса запускай `npm test`.

## Следующее развитие

Основой следующих итераций могут стать сюжетные события на маршрутах, размещение мебели игроком, больше форм изделий, новые истории и полноценное звуковое оформление. Экономика требует дальнейшего тестирования с реальными игроками. Код и графика находятся в этом репозитории; внешние изображения и шрифты не используются.

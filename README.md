# Бестиарий Велена

Велен, 1740. Тебе достался бестиарий старого хранителя Даро: многое в нём проверено, многое записано со слухов, а
многого нет вовсе. Охотники приходят с делами — «волколак в Заречье», — и ты пишешь каждому ровно **три указания**.
Каждое верное даёт треть успеха, три верных — победу наверняка. Утром охотник возвращается и рассказывает по каждому
указанию: «Помогло», «Без толку» или «Во вред», — и печати в бестиарии меняются сами.

**Играть:** https://viDaLost.github.io/Pix/ — мобильная офлайн-игра (PWA), чистый JavaScript без сборщика.

## Как играть

1. **Приёмная:** выслушай гостя и открой лист совета.
2. Выбери три листка сведений, по одному на род: чем бить, чем уберечься, когда, где, как.
3. Полоса под листом — оценка по твоим записям; «Опасно» советовать нельзя. Снадобья — по желанию, сверху.
4. **Задуй свечу** — ночью идут охоты, утром приходят отчёты с ранами или наградой.
5. **Опыты** проверяют слухи на образцах и в летописях, **Лавка** продаёт книги, слухи и листы Академии.
6. Цель — четырнадцать трактатов и «Великий бестиарий» до конца Чёрной зимы; первый день — урок Даро на волколаке.

## Запуск и проверки

Нужен Node.js 22+, npm-зависимости не нужны.

```sh
npm start          # http://localhost:4173/Pix/
npm run check      # синтаксис модулей, скриптов и тестов
npm test           # node:test
npm run balance    # бот баланса; --write обновляет docs/BALANCE.md
npm run build      # dist/ для GitHub Pages
```

Сохранение лежит на устройстве (IndexedDB `pix-bestiary` и `localStorage`), скачивается и загружается файлом из меню.
Сохранение прежней игры не трогается: меню предлагает скачать его файлом. Ручная проверка — `docs/PLAYTEST.md`.

## Модули

| Файл | Назначение |
| --- | --- |
| `src/content-data.js`, `src/lore.js` | Контент (14 чудовищ, сведения, охотники, гости, сюжет, строки) и доступ к нему со склонениями |
| `src/rng.js`, `src/rules.js` | Бросок по зерну мира; чистая математика шансов, оценок, ран и званий |
| `src/bestiary.js`, `src/progress.js` | Ядро: состояние, знание, дела дня, ночь, отчёты; сюжет, арки, `normalize` и обёртки `P.*` |
| `src/guide.js` | Без DOM: очередь, «Сегодня», карточка «Утро», урок первого дня и подсказки Даро |
| `src/app.js`, `styles.css`, `index.html` | Оболочка: HUD, пять вкладок, лист совета, отчёт, окна, меню, наставник |
| `src/notices.js`, `src/store.js` | Очередь тостов и окон; хранилище с защитой вкладок и чтение прежнего сохранения |
| `src/scriptorium-scene.js`, `src/item-art.js`, `src/icons.js` | Пиксельный скрипторий, лаборатория, порог отчёта; значки вещей и интерфейса |
| `src/characters.js`, `src/character-rig.js`, `src/motion.js`, `src/pixel.js` | Пиксельные люди, позы, походка |
| `src/engraving.js`, `src/plates.js` | Гравюры чудовищ: штриховка, стадии изученности, 14 досок |
| `src/report-reveal.js`, `src/ambience.js`, `src/audio.js` | Раскрытие отчёта; время суток и погода; звуки, музыка, вибрация |
| `scripts/*.mjs`, `tests/*.test.mjs` | Сервер, сборка, проверки, бот баланса; тесты правил, сохранений, офлайна и интерфейса |
